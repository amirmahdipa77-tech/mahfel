# پرامپت — کنسول گفت‌وگو با مدل‌های زبانی

یک اپلیکیشن تک‌صفحه‌ای و بدون بک‌اند برای گفت‌وگو با مدل‌های زبانی، با ظاهر کنسول/ترمینال. فارسی و راست‌به‌چپ، سبک، و کاملاً در مرورگر.

نسخهٔ منتشرشده: <https://amirmahdipa77-tech.github.io/mahfel/>

بازی‌های قبلی هم سر جای خودشان هستند: [`chahar.html`](chahar.html) (چهارتایی)، [`doz.html`](doz.html) (دوز)، [`mafia.html`](mafia.html) (مافیا).

## چه چیزی دارد

- **استریم پاسخ**: پاسخ کلمه‌به‌کلمه می‌آید، با دکمهٔ توقف هر لحظه.
- **رندر مارک‌داون**: تیتر، لیست، نقل‌قول، کد درون‌خطی و بلوک کد با برچسب زبان و دکمهٔ کپی (رندرر امن و داخلی، بدون کتابخانهٔ بیرونی).
- **چند ارائه‌دهنده**: هر سرویس سازگار با OpenAI — OpenAI، OpenRouter، Groq، Together، Ollama یا LM Studio محلی — با پریست آماده و امکان آدرس دلخواه.
- **حالت نمایشی**: بدون کلید و بدون اینترنت کار می‌کند تا رابط را ببینی (پاسخ‌های نمونه با همان استریم).
- **تاریخچهٔ گفت‌وگوها** در `localStorage`، با عنوان خودکار، حذف و بازیابی.
- **پرامپت سیستمی، temperature، انتخاب مدل** و آزمایش اتصال (`/models`).
- **دستورهای متنی**: `/model`، `/system`، `/clear`، `/export`، `/new`، `/help`.
- **کلیدهای میان‌بر**: `Enter` ارسال، `Shift+Enter` خط تازه، `⌘/Ctrl+K` گفت‌وگوی تازه، `Esc` بستن پنل.
- **خروجی مارک‌داون** از هر گفت‌وگو.
- **پوستهٔ روشن/تیره** با ذخیرهٔ انتخاب، و طراحی واکنش‌گرا برای موبایل.

## چطور وصلش کنم

۱. آیکن چرخ‌دنده (تنظیمات اتصال) را باز کن.
۲. یک ارائه‌دهنده انتخاب کن یا آدرس پایه و مدل را دستی بگذار.
۳. کلید API را وارد کن و «آزمایش اتصال» را بزن.

مثال با Ollama روی سیستم خودت:

```bash
ollama serve
ollama pull llama3.2
# در تنظیمات: آدرس پایه http://localhost:11434/v1 و مدل llama3.2 (کلید لازم نیست)
```

## حریم خصوصی و امنیت

- هیچ سرور واسطی وجود ندارد؛ درخواست مستقیم از مرورگر تو به همان آدرس پایه‌ای می‌رود که خودت وارد کرده‌ای.
- کلید API فقط در `localStorage` همین مرورگر ذخیره می‌شود و به هیچ جای دیگری فرستاده نمی‌شود. روی کامپیوتر شخصی مشکلی نیست؛ روی دستگاه مشترک بعد از استفاده پاکش کن.
- رندرر مارک‌داون اول همه‌چیز را escape می‌کند و بعد فقط تگ‌های مجاز را می‌سازد؛ بنابراین پاسخ مدل نمی‌تواند HTML یا اسکریپت تزریق کند.
- لینک‌ها با `rel="noopener noreferrer"` و در تب تازه باز می‌شوند.

## چرا مستقیم به duck.ai وصل نیست

DuckDuckGo برای چت خود API عمومی منتشر نکرده است. مسیری که کلاینت‌های غیررسمی استفاده می‌کنند یک پروتکل داخلی با توکن موقت (`vqd`) و بررسی ضدربات است که:

1. از مرورگر قابل فراخوانی نیست (CORS)، پس به یک پروکسی سرور نیاز دارد؛
2. با هر تغییر کوچک سمت سرویس می‌شکند؛
3. استفاده از آن خارج از شرایط سرویس است.

به همین دلیل این کنسول روی استاندارد باز OpenAI ساخته شده: با کلید خودت، با هر ارائه‌دهنده‌ای، یا با مدل محلی — بدون واسطه و بدون شکنندگی.

## ساختار فایل

همه‌چیز در یک فایل `index.html` است: استایل‌ها، رندرر مارک‌داون، کلاینت SSE و رابط. بدون وابستگی npm و بدون مرحلهٔ build؛ فقط دو فونت از Google Fonts.
