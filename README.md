# محفل — بازی مافیای آنلاین

یک صفحهٔ وب تک‌صفحه‌ای (فارسی، راست‌به‌چپ) برای بازی مافیا به‌صورت هم‌زمان، ساخته‌شده روی **Supabase Realtime**.

نسخهٔ منتشرشده: <https://amirmahdipa77-tech.github.io/mahfel/>

## چه چیزی داخلش هست

- **حساب کاربری سبک**: ثبت‌نام و ورود فقط با نام کاربری و گذرواژه (بدون ایمیل). نشست با توکن در مرورگر ذخیره می‌شود.
- **اتاق‌ها**: اتاق باز، خصوصی (با لینک دعوت) و بسته. هر اتاق چت زنده، فهرست اعضا و شمارندهٔ آنلاین دارد.
- **بازی کامل مافیا**: نقش‌های مافیا، شهروند، دکتر و کارآگاه؛ فازهای شب → روز → رأی‌گیری → نتیجه با شمارش معکوس.
- **هم‌گامی**: اشتراک `postgres_changes` روی جدول‌های `games` و `messages` به‌همراه یک حلقهٔ همگام‌سازی هر ۲ ثانیه، تا حتی اگر WebSocket قطع شود بازی عقب نماند.
- **رابط کاربری**: طراحی تیره با فونت وزیرمتن، کاملاً واکنش‌گرا (موبایل و دسکتاپ).

## پشت صحنه

تمام منطق بازی سمت دیتابیس و در توابع `SECURITY DEFINER` پروژهٔ Supabase اجرا می‌شود؛ صفحهٔ وب فقط این توابع را صدا می‌زند:

| تابع | کار |
| --- | --- |
| `mahfel_signup` / `mahfel_login` / `mahfel_me` / `mahfel_logout` | حساب و نشست |
| `rooms_list` / `room_create` / `room_get` / `room_join` / `room_leave` / `room_ping` | اتاق‌ها و حضور آنلاین |
| `messages_list` / `send_message` | چت اتاق |
| `game_create` / `game_ready` / `game_start` / `game_view` | چرخهٔ بازی |
| `game_action` / `game_advance` / `game_tick` | حرکت‌ها، رأی‌گیری و پیشبرد فازها |

جدول‌های `games` و `messages` در publication مربوط به Realtime هستند و سیاست‌های خواندن (RLS) برای نقش `anon` باز است؛ بقیهٔ نوشتن‌ها فقط از طریق توابع انجام می‌شود.

## اجرا روی سیستم خودت

فایل `index.html` کاملاً مستقل است. کافی است آن را باز کنی:

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

برای اتصال به پروژهٔ Supabase خودت، مقدارهای `SB_URL` و `SB_KEY` بالای `<script type="module">` را عوض کن.

## انتشار روی GitHub Pages

این مخزن روی شاخهٔ `main` و از ریشهٔ پروژه با GitHub Pages منتشر می‌شود؛ هر push روی `main` سایت را به‌روز می‌کند.

## نکتهٔ امنیتی

کلید عمومی (anon/publishable) در فایل صفحه قابل مشاهده است و این طبیعی است؛ امنیت از طریق توابع سمت دیتابیس و سیاست‌های RLS تأمین می‌شود. برای پروژه‌های واقعی، محدودسازی نرخ درخواست و بازبینی سیاست‌های RLS را جدی بگیر.
